## ⚡ Core Concepts & Experiments

### 1. The Recursive Feedback Loop ($N \to N+1$)
Standard generative AI tools treat image generation as an isolated, one-shot prompt request. **DIGITAL_DECAY** turns the model into an open-loop analog video synthesizer:
* Frame $0$ is latched from an uploaded image or live optical camera sensor.
* Frame $N$ is fed back as the direct visual tensor input for Frame $N+1$ across **69 generations**.
* Neural misinterpretations, compression artifacts, and edge blur compound over time, transforming mundane source imagery into stabilized, surreal "Hero Artifacts."

### 2. Parametric Entropy Coefficient
The model's temperature parameter ($0.1$ to $1.9$) is exposed as a tactile **Entropy Coefficient**:
* **Strict Replication ($0.1$ - $0.7$):** Suppresses hallucination, forcing the model to struggle with exact pixel preservation, producing subtle analog drift and vector smoothing.
* **Balanced Decay ($0.8$ - $1.2$):** Classic generational loss where familiar structures melt and mutate over dozens of iterations.
* **Chaotic Manifestation ($1.3$ - $1.9$):** Amplifies neural stochasticity, forcing the model into dream-like hallucinations and rapid structural divergence.

### 3. Procedural Signal Degradation Injections
Procedural degradation tokens inject synthetic digital trauma into each cycle:
* **Bitcrush:** Downsamples input tensors to 128px to force pixelation and early semantic distortion.
* **Chromatic Aberration:** Induces R/G/B channel drift and optical prism separation.
* **JPEG Block Artifacts:** Simulates 8x8 DCT compression quantizations.
* **Scanline Ghosting:** Recreates vintage CRT phosphor decay and electron gun bleed.
* **Datamashing:** Simulates P-frame visual carryover and codec drift.
* **VHS Distortion:** Injects luma noise, tracking flutter, and tape head saturation.

### 4. Zero-Cost BYOK (Bring Your Own Key) Architecture
* **Zero Backend Costs:** Designed to run 100% client-side on **GitHub Pages** with no hosted server or database fees.
* **1-Click Clipboard Bridge:** Visitors connect their free Gemini API key with one click (`navigator.clipboard.readText()`), securely stored in local device memory (`localStorage`).
* **Instant URL Scrubbing:** Keys provided via URL parameter (`?gemini_api_key=...`) are immediately wiped from the browser address bar upon boot to prevent shoulder-surfing, URL sharing leaks, or browser history persistence.

### 5. Cyber / SGI Retro Terminal Aesthetic
* Synthesized Web Audio engine recreating vintage hard drive spindle spin-up, stepper motor seek chatter, and high-pitch BIOS POST confirmation beeps.
* Interactive before/after split slider, scrubbing playback timeline, and client-side animated GIF compilation via Web Workers.

## 🚀 Instant Deployment on GitHub Pages

This repository is pre-configured with a GitHub Actions workflow (`.github/workflows/deploy.yml`) for automated zero-cost hosting.

1. **Fork or push this repository to GitHub.**
2. Go to **Settings > Pages** in your GitHub repository.
3. Under **Build and deployment > Source**, select **GitHub Actions**.
4. Every push to `main` will build and publish your site automatically!
